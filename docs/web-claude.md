# 웹 Claude 학습 안내

개념 공부(수식, 손으로 풀기, 질문)는 웹 Claude(claude.ai)에서 하고, 코드·데이터·커밋은 Claude Code에서 한다.
웹 Claude는 수식을 제대로 그려 주고 대화를 길게 이어 가기 좋다.

## 처음 한 번: 프로젝트 만들기

1. claude.ai → Projects → 새 프로젝트 `RouteMind 학습`
2. 프로젝트 지식(Files)에 `README.md`, `CLAUDE.md` 첨부. 1단계부터는 그 주에 쓴 노트(`docs/week-XX/*.md`)도 추가
3. 프로젝트 지침(Instructions)에 아래 블록을 붙여 넣기

```text
나는 물류와 최적화를 처음 배우는 사람이다. 첨부한 README의 RouteMind 프로젝트(CJ대한통운 '최적화' 직무 지원용 포트폴리오)를 만들면서 필요한 개념을 배운다. 문제 정의와 일정은 README와 CLAUDE.md에 있다.

가르치는 방식
- 직관 → 수식 → 코드 순서로 설명한다. 사람이라면 어떻게 풀지 먼저 생각하게 하고, 그 판단을 수식으로 옮긴다.
- 한 번에 개념 하나만 다룬다. 작은 숫자 예제(허브 2~3곳, 고객 3~5곳)로 손으로 계산할 수 있게 한다.
- 답을 바로 주지 말고 질문으로 이끈다. 내가 막히면 힌트를 한 단계씩 준다. "답 알려줘"라고 하면 그때 답을 준다.
- 수식은 LaTeX로 쓰고, 기호마다 뜻을 말로 함께 적는다.
- 개념을 설명한 뒤에는 면접에서 받을 법한 질문 하나로 내가 이해했는지 확인한다.
- 코드는 Claude Code에서 직접 쓰므로 여기서는 개념 중심으로 하고, 필요하면 PuLP 예시를 짧게만 보여 준다.

"오늘 정리해줘"라고 하면 아래 형식의 마크다운 노트를 만든다. 내가 저장소 docs/week-XX/ 에 저장한다.

# <주제>
## 한 줄 요약
## 직관 (말로)
## 수식 (기호 뜻 포함)
## 손으로 푼 예제
## 헷갈렸던 점과 해결
## 면접 질문과 내 답
## RouteMind에서 쓰이는 곳
```

## 첫 대화: 아래 블록을 그대로 붙여 넣기

```text
수송 문제(transportation problem)를 처음부터 배우고 싶어. 지금까지 진행한 내용이야.

문제: 허브 2곳, 고객 3곳. 수송비 = 거리(km) × 무게(kg). 한 고객의 물량을 두 허브로 나눠 보내도 된다.

| 거리 (km) | 고객 1 (30kg) | 고객 2 (25kg) | 고객 3 (20kg) | 용량 |
|---|---|---|---|---|
| 허브 A | 2 | 4 | 5 | 40kg |
| 허브 B | 3 | 1 | 7 | 40kg |

직관으로 푸는 중:
1단계. 모두 가장 가까운 허브로 보낸다 → 고객 1은 A, 고객 2는 B, 고객 3은 A
2단계. 용량 확인 → A가 30 + 20 = 50kg로 용량 40kg를 10kg 넘는다. B는 25kg로 여유
3단계. 넘친 10kg을 누구에게서 덜어 B로 보낼까? 1kg을 B로 옮길 때 비용이 덜 늘어나는 쪽을 골라야 한다.
  - 고객 1: 2km → 3km, +1km
  - 고객 3: 5km → 7km, +?km

여기서 막혔어. 3단계부터 같이 풀고, 그다음 내가 한 판단이 결정변수·목적함수·제약으로 어떻게 바뀌는지 알려줘.
이후 순서는 수송 문제 → UFLP(허브 개설 여부 y_j와 고정비 추가) → CFLP(용량·냉장 제약, README 1단계 모델)야.
```

## 공부가 끝나면

1. 웹 Claude에 "오늘 정리해줘" → 노트를 받는다
2. 내 말로 고쳐서 `docs/week-XX/<주제>.md`로 저장한다 (면접에서 내 말로 설명해야 하므로 그대로 붙이지 않는다)
3. 코드로 옮길 차례면 Claude Code에서 이어서 한다
